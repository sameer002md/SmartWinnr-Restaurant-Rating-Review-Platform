# SmartWinnr submission checklist

- [ ] Frontend starts with `npm install` and `npm run dev`.
- [ ] Backend starts with `npm install` and `npm run dev`.
- [ ] MongoDB connection succeeds and `/api/health` responds.
- [ ] Customer registration/login works.
- [ ] Customer can create one review per restaurant, view it, update it, and delete only their own review.
- [ ] Owner can view/update only their assigned restaurant and view its reviews.
- [ ] Admin can manage users/restaurants, create owners, assign owners, view/remove reviews, and view dashboard statistics.
- [ ] Import and run `postman/SmartWinnr.postman_collection.json`.
- [ ] Add actual sample role credentials to a private handover note only if required; never publish passwords.
- [ ] Ensure `.env` and secrets are excluded from Git.
- [ ] Push all source files, README, `.env.example`, and Postman collection.
- [ ] Open the GitHub repository in a private/incognito window to confirm the submitted files are visible.
